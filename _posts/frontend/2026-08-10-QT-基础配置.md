Ubuntu的wayland协议不支持应用程序自行设置置顶，只能通过标题栏右键的always on top功能实现。故仅展示实时数据的应用可以绑定在系统的状态栏上以文本形式展现，如MacOS的CPU监视工具：

```
Finder   File   Edit   View   ...        CPU 23%   23:42
```
